# Asset Conventions

- Treat `Images/Intro/Scenes/` as the folder for course-introduction video scene images when those scene files are explicitly organized there.
- Treat `Images/Intro/Support/` as the preferred folder for course-introduction support-note infographics when those support files are explicitly organized there.
- Always verify the exact file that exists in the project before wiring an HTML image reference. Do not point pages at a planned folder if the asset only exists elsewhere.
- Do not substitute video scene images for support-note infographics unless the source content explicitly names the same file for both roles.
- When a required infographic file is genuinely missing, keep the intended educational content and render a clean placeholder with the infographic title instead of exposing a broken image icon.
- Apply the same scene-versus-support distinction and missing-image handling across later modules.
